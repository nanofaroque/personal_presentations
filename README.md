# Research, Patents & Technical Writing

A living archive of original research, granted patents, peer-reviewed publications, open-source tools, conference talks, and long-form technical writing — spanning distributed systems, computer security, machine learning infrastructure, and foundational computer science.

This repository serves as both the source and the deployed site for my collected works. Each piece represents a deep investigation into the systems, algorithms, and security boundaries that underpin modern computing at scale.

**[Browse the full collection →](https://nanofaroque.github.io/personal_presentations/)**

---

## What's Inside

- **Patents** — Granted and pending inventions in distributed tracing, network traffic routing, proxy manifest generation, and certificate lifecycle management.
- **Publications** — Peer-reviewed papers including a Best Paper award at KCS 2024 for *Eyana: The SSD Simulator*, and work published through Springer.
- **Tools** — Interactive simulators for exploring hardware internals (SSD architecture, quantum computing models).
- **Talks** — Invited lectures at universities and industry organizations on database internals, cloud infrastructure, and data systems.
- **Technical Writing** — Deep dives into metastable failures, shuffle sharding, serialization formats, prompt injection attacks, compute-optimal training, and more.
